# Nebula Labs

Nebula Labs is an independent educational data platform that combines data
collection and parsing tools with a Go API service.

## Repository layout

- `services/api-tools` — scraping, parsing, validation, and upload workflows.
- `services/nebula-api` — REST API and shared data schemas.

Future work will replace that configuration and data model with independently
owned infrastructure and product features.
